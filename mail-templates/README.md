# Mailteksten (Supabase Auth)

In te plakken in Supabase → Authentication → Emails → Templates. Bron hier, zodat ze bewaard blijven.

| Template in Supabase | Onderwerp | Bestand |
|---|---|---|
| Invite user | Je projectpagina bij Vonstruct staat klaar | uitnodiging.html |
| Magic Link | Inloggen bij Vonstruct | inloglink.html |
| Reset Password | Nieuw wachtwoord voor je Vonstruct-pagina | wachtwoord.html |

Logo: https://app.vonstruct.com/mail-logo.png (map `public/`).
